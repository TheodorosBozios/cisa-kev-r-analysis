# Data source

**Catalogue:** CISA Known Exploited Vulnerabilities (KEV)

**Official page:** https://www.cisa.gov/known-exploited-vulnerabilities-catalog

**Snapshot in this project:** retrieved 12 October 2026 · 1,739 CVE entries · 12 columns

**Fields used:** cveID, vendorProject, product, vulnerabilityName, dateAdded, shortDescription, requiredAction, dueDate, knownRansomwareCampaignUse, forensicTriage, notes, cwes

The raw CSV under `data/raw/cisa_kev.csv` is included in the full project ZIP. Analysis never overwrites this file.
